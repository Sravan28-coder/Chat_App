# 💬 Real-Time Chat App

A simple real-time chat application built with **Node.js**, **Express**, **Socket.IO**, and **MongoDB**. Users can send messages that appear instantly to everyone connected.

## 🚀 Features

- Real-time messaging with WebSockets (via Socket.IO)
- Basic chat UI (HTML/CSS/JavaScript frontend)
- Message persistence using MongoDB (via Mongoose)
- Broadcast messages to all connected users
- Simple and clean interface
